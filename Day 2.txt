LOGICAL OPERATORS

$and       $or      $not       $nor
1.	Find students who belong to the CSE department AND have marks greater than 85.
db.students.find({
    $and: [
        { department: "CSE" },
        { marks: { $gt: 85 } }
    ]
})
2.	Find students who belong to CSE OR IT.
db.students.find({
    $or: [
        { department: "CSE" },
        { department: "IT" }
    ]
})
3.	Find students whose marks are NOT greater than 80.
db.students.find({
    marks: {
        $not: {
            $gt: 80
        }
    }
})
4.	Find students who are neither from CSE nor from IT.
db.students.find({
    $nor: [
        { department: "CSE" },
        { department: "IT" }
    ] })

ARRAY OPERATORS
$in                    $nin                      $all                        $elemMatch            $size

db.students.find({

    }
})

MongoDB — Update Operations
MongoDB provides several operations for modifying existing documents:
updateOne()
updateMany()
replaceOne()

What is updateOne() in MongoDB?
updateOne() is used to modify the first document that matches a specified condition.
Syntax:
db.collection.updateOne(
    { filter },
    { update })
1.	Change the price of Product 1 to 10000.
db.products.updateOne(
    { productId: 1 },
    { $set: { price: 10000 } } )

Updating Multiple Fields
1.	Update the price and stock of Product 2.
db.products.updateOne(
    { productId: 2 },
    {
        $set: {
            price: 15000,
            stock: 100
        }
    }
)
2.	Change the seller name of Product 3 to "Premium Seller".
db.products.updateOne(
    { productId: 3 },
    {
        $set: {
            "seller.sellerName": "Premium Seller"
        }
    }
)

3.	Add "sale" to the tags array of Product 4.
db.products.updateOne(
    { productId: 4 },
    {
        $push: {
            tags: "sale"
        }
    }
)
4.	Add "electronics" to the tags of Product 5 without creating a duplicate.
db.products.updateOne(
    { productId: 5 },
    {
        $addToSet: {
            tags: "electronics" } } )
$inc
$inc is used to increase or decrease a numeric field.
5.	Increase the stock of Product 6 by 20.
db.products.updateOne(
    { productId: 6 },
    {
        $inc: {
            stock: 20
        }
    }
)
6.	Decrease the stock of Product 6 by 5.
Answer:
db.products.updateOne(
    { productId: 6 },
    {
        $inc: {
            stock: -5
        }
    }
)
updateMany()
Now we move from one document → multiple documents.
1.	Set inStock to true for all products belonging to the Laptop category.
db.products.updateMany(
    { category: "Laptop" },
    {
        $set: {
            inStock: true
        }
    }
)
2.	Increase the price of all Samsung products by 1000.
db.products.updateMany(
    { brand: "Samsung" },
    {
        $inc: {
            price: 1000
        }
    }
)
Example using multiple operators
db.products.updateOne(
    { productId: 10 },
    {
        $set: {
            price: 25000,
            inStock: true
        },
        $inc: {
            stock: 10
        },
        $push: {
            tags: "sale" }})

MongoDB — Delete Operations
MongoDB mainly provides two deletion methods:
deleteOne()
deleteMany()

deleteOne()
What is deleteOne()?
deleteOne() is used to delete the first document that matches a specified condition.
Syntax:
db.collection.deleteOne({
    condition
})
1.	Delete the product whose productId is 10.
db.products.deleteOne({
    productId: 10
})

deleteMany()
What is deleteMany()?
deleteMany() is used to delete all documents that match a specified condition.
Syntax:
db.collection.deleteMany({
    condition
})
1.	Delete all products belonging to the Laptop category.
db.products.deleteMany({
    category: "Laptop"
})
2.	Delete all products whose price is greater than 30000.
Answer:
db.products.deleteMany({
    price: {
        $gt: 30000
    }
})
3.	How do you delete all documents from the products collection without deleting the collection itself?
db.products.deleteMany({})
